# Проверки SACRA / TUI Lab 0.2

Этот отчёт зафиксировал проверки браузерного TUI-референса до его интеграции в `sacra-ui-kit`.
Он не подтверждает совместимость с нативным терминальным приложением. Предыдущий отчёт сохранён отдельно: `QA-0.1.md`.

## Выполнено

| Проверка | Результат |
|---|---|
| Синтаксис `assets/*.js`, `examples/*.js` через `node --check` | Без ошибок |
| `node tests/charts.test.cjs` | 15/15 |
| `node tests/coordinates-themes.test.cjs` | 17/17 |
| `python3 tests/browser.py` | 75/75 |
| `python3 tests/themes_browser.py` | 150/150 |
| Браузер | Chromium 144.0.7559.96 |

Списки сценариев — в `tests/browser-results.json` и `tests/themes-browser-results.json`.
Количество успешных проверок не означает полный аудит всех состояний и браузеров.

## Что проверялось дополнительно

- Действительные координаты X/Y; [0,100], [0,16], [0,32]; несимметричный отрицательный
  диапазон и положение Y=0; форматы времени, сокращение количества меток на узком графике.
- Пунктирный периметр, направляющие и кресты одинаковы в Pixels, Octant и ASCII.
  Прозрачный Canvas не закрашивает независимую SVG-рамку.
- `g`/кнопка/checkbox управляют одной сеткой. Её отключение не убирает числовые шкалы.
- Курсор с двумя координатами, реальные ближайшие samples, шаг 1s в пятиминутном окне,
  две сетевые серии; null не создаёт вымышленную точку, zero остаётся на baseline.
- Восемь пресетов и по 17 ролей в каждом; реестры JS/JSON идентичны. SACRA сохраняет
  оригинальные цвета; неизвестный ID безопасно возвращает базовую тему.
- Собственный селектор, radio-стрелки, t, Enter, Esc, живой предпросмотр, отмена, reset,
  JSON-экспорт, возврат фокуса. Тема перекрашивает Canvas даже на паузе.
- Переключение не сбрасывает введённое имя, данные задач и paused-состояние.
  Browser wrapper остаётся в базовой палитре. Светлая тема меняет реальный foreground,
  а не только CSS-переменную без наследования.
- Все 8 тем × 5 экранов на 390 и 1440 px; окно палитр на 320 px. Отдельно прежняя
  регрессия всех экранов на 320/390/768/1440/1920 px и ширины TUI 80/120/160/AUTO.
- Независимый `examples/minimal-chart.html`: общая координатная модель без app.js,
  61 числовой sample, 10 пропусков, таблица данных, ширины 320/390/768/1440 px.
- Нет ошибок JavaScript и сетевых запросов приложения в проверенных сценариях.
  Прежние clipboard-сценарии проверяют фактическую вставку и ручной fallback при отказе.

## Граница браузерной проверки

Политика рабочего браузерного контейнера блокирует переходы на `file://`, локальный HTTP
и тестовый HTTPS origin. Использована загрузка **тех же исходников** через Playwright
`set_content`, `add_style_tag`, `add_script_tag`. Перед загрузкой проверены относительные
пути ресурсов. Это проверка интерфейса/исходников, **не E2E открытия скачанного ZIP**.

Отсутствие origin в такой тестовой странице не позволяет проверять настоящий localStorage
обычным reload. Для проверки записи, отсутствия записи во время preview и восстановления
при новом старте использован контролируемый Storage adapter. Отдельно проверена ветка
отказа доступа к хранилищу: тема применяется, но сообщение не заявляет о сохранении.
Фактическое сохранение между открытиями локального файла в Safari не тестировалось.

## Скриншоты

Все поставляемые PNG перерендерены для 0.2 в этом Chromium. `palettes-overview.png` —
подписанный монтаж восьми реальных кадров одного и того же графика; не вручную нарисованная
имитация. `render-info.json` фиксирует способ загрузки и браузер. Данные синтетические.

## Не проверено / не реализовано

Safari/macOS, iOS, VoiceOver, физическая клавиатура мобильного устройства и native terminal
не проверялись. Нет Kitty transport, ANSI/PTY-эмулятора, импорта btop `.theme`, настоящих
метрик компьютера или системных операций. Mono — палитра, не ANSI/256-color backend.
Числовая проверка контраста касается text/muted/accent к canvas; это не полный WCAG-аудит.
