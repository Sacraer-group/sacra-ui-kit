# Палитры SACRA / TUI 0.2

Темы меняют **цветовые роли**, а не оформление компонентов. Геометрия, расстояния,
рамки, шрифт и клавиатурное поведение одинаковы. SACRA Graphite всегда тема по умолчанию.

| ID | Название | Идея |
|---|---|---|
| `sacra` | SACRA Graphite | Исходные 17 цветов SACRA 1.4.3, без изменений |
| `nord` | Nord | Холодный графит, ледяной акцент |
| `gruvbox` | Gruvbox Dark | Тёплый графит, янтарный акцент |
| `dracula` | Dracula | Тёмная слива, лиловый акцент |
| `tokyo` | Tokyo Night | Чернильный фон, голубой акцент |
| `solarized` | Solarized Dark | Сине-зелёный тёмный фон, охристый акцент |
| `solarized-light` | Solarized Light | Светлая бумага и тёмные чернила |
| `mono` | Mono Graphite | Градации графита; текстовые [OK]/[ERR] обязательны |

## Поведение

Кнопка палитры или `t` внутри TUI открывает собственный диалог. Radio-список работает мышью,
клавиатурой и касанием. Выбор сразу показывает цвета, а не запускает новый экран.
Enter на варианте или «Применить» фиксирует его. Esc / «Отмена» восстанавливает предыдущий.
Кнопка SACRA — предпросмотр базовой темы; её тоже можно отменить.

Не изменяются введённое имя, выбранная задача, её локальное состояние, сценарий графика,
временное окно, пауза и размеры. Курсор графика не используется как команда изменения темы.

## Scoping

`assets/tokens.css` сохраняет исходную базовую палитру. `TuiThemes.apply` устанавливает
все роли на корнях с `data-tui-theme-root`: TUI, диалогах и уведомлении. Внешняя браузерная
обложка не перекрашивается. Каждый Canvas читает текущую палитру при перерисовке;
поэтому старый RGB-кэш не оставляет жёлтые линии после выбора Nord или Dracula.

Полные графики: первая серия — `accent`, вторая — `text`; разделение также дано легендой.
Цвет сетки — `border-strong`, она приглушена отдельно. Ноль, пропуски и масштаб не зависят
от темы. В светлой теме основной текст тоже меняется на тёмный — не только фон.

## Хранение и экспорт

Ключ `localStorage`: `sacra-tui-theme-v1`. Хранится только разрешённый ID. Неизвестный ID
превращается в `sacra`. Нет сетевых запросов, учётных данных и изменения настроек терминала.

При недоступном хранилище применение всё равно работает в текущей сессии; сообщение явно
говорит, что выбор не сохранён. Поведение localStorage у локальных файлов зависит от браузера.
Для устойчивого origin можно раздать папку локальным HTTP-сервером из README.

Кнопка «↓ JSON» экспортирует текущие роли. Это **не** `.theme` btop, не ANSI-палитра и не
автоматическая установка темы. Загрузчик произвольных тем в этой версии не добавлен.
Для разработчика реестр — `assets/themes.js`, его JSON-копия — `assets/themes.json`;
тест проверяет их идентичность.

## Источники и изменения

Названия и цветовые семьи сверены по каталогу тем btop:

| Семейство | Первичный файл | Автор/примечание из файла |
|---|---|---|
| Nord | [nord.theme](https://github.com/aristocratos/btop/blob/main/themes/nord.theme) | Justin Zobel; Nord palette |
| Gruvbox | [gruvbox_dark.theme](https://github.com/aristocratos/btop/blob/main/themes/gruvbox_dark.theme) | BachoSeven; gruvbox |
| Dracula | [dracula.theme](https://github.com/aristocratos/btop/blob/main/themes/dracula.theme) | Dracula family |
| Tokyo Night | [tokyo-night.theme](https://github.com/aristocratos/btop/blob/main/themes/tokyo-night.theme) | Pascal Jaeger |
| Solarized Dark | [solarized_dark.theme](https://github.com/aristocratos/btop/blob/main/themes/solarized_dark.theme) | Solarized family |
| Solarized Light | [solarized_light.theme](https://github.com/aristocratos/btop/blob/main/themes/solarized_light.theme) | Modified from Solarized Dark |

Это адаптация к 17 ролям SACRA, **не точная копия каждого HEX исходной темы**. Часть текста,
вторичных поверхностей, границ и акцентов выбрана отдельно для читаемости. Собственные
SACRA/Mono пресеты не объявляются встроенными темами btop. Gradient-графики и стили btop
не переносились; темы ultra-mog не использовались.

Выполнена числовая проверка контраста text, muted и accent к canvas не ниже 4.5:1
для каждого пресета. Это **не полный WCAG-аудит** всех пар состояний/поверхностей;
семантика дополнительно выражается метками, символами, рамками и текстом.
