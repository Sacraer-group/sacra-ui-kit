# Каталог TUI-компонентов

| Компонент | Иерархия и оформление | Поведение в симуляции |
|---|---|---|
| App chrome | title → tabs → context → panels → status → keybar | 5 экранов, текущий маршрут, режим паузы |
| Panel/frame | прямые линии, заголовок в разрыве верхней рамки | рамка получает accent темы при фокусе внутри |
| Sidebar/tree | вложенность в клетках, короткие подписи | переходы экранов; раскрываемые details |
| Table | горизонтальные разделители, числа справа | выбор, поиск, фильтры, сортировка в задачах |
| Inspector | справа или под таблицей | то же состояние выбранной задачи; Summary/JSON |
| Metric | имя → величина → единица → sparkline | синтетические значения раз в секунду |
| History chart | пунктирная координатная рамка, угловые кресты, деления, действительные шкалы | Pixels/Octant/ASCII, двумерный курсор, g — направляющие |
| Theme picker | своё окно, radio-список, цветовые образцы, живой preview | t, стрелки, Enter — применить/сохранить, Esc — откатить |
| Button | `[key] Действие`, primary — акцент темы | реальные действия интерфейса, не shell |
| Checkbox | `[ ]` / `[×]` + текст | Space; сетка и автообновление привязаны к состоянию |
| Radio | `( )` / `(•)` + текст | нативная группа, сохраняет локальный выбор |
| Select | value + `[▾]`, квадратный список | свой DOM listbox; стрелки/Home/End, Enter, Esc |
| Input | тёмный inset, нижняя линия | имя 2–24 символа, текст ошибки и aria-invalid |
| Tabs | короткая подпись, активная нижняя линия | roving tabindex, Left/Right/Home/End |
| Progress | значение + фиксированная полоса + метка | +10%, reset; отдельный demo-progress |
| Spinner | один знакоместный символ | только пока симуляция запущена |
| Pagination | `← page / total →` | смена трёх строк; отключённые крайние действия |
| Status | `[OK]`, `[RUN]`, `[ERR]`, `[N/A]` | смысл передаётся текстом, не только цветом |
| Empty/error | краткая причина, отдельная форма | не подставлять fake-zero |
| Logs | время → уровень → текст | статический пример журнала, явно demo |
| Code block | inset, сохранение форматирования | JSON выбранной задачи, копирование |
| Command palette | `:` поле + список действий | поиск, стрелки и Enter; без исполнения команд ОС |
| Confirm dialog | заголовок, объект, переход состояния | Esc отменяет, отдельная кнопка подтверждает |
| Copy feedback | `[✓]` / notification | только после записи; при отказе ручной текст |

## Публичные точки прототипа

`assets/charts.js` экспортирует `TuiCharts` в браузере и CommonJS для тестов:

- `segments(history, key, windowMs, end?)` → массив непрерывных сегментов `[x, y]`;
- `raster(spec)` → RGBA-буфер и маска индекса серии;
- `ascii(frame, grid = true)` → символьное представление;
- `spark(values, width, asciiOnly, peak?)`;
- `bar(value, width, asciiOnly)`;
- `sample(timestampMs)` → детерминированный demo-sample.

`SacraTUI` в браузере — интерфейс **лаборатории**, не стабильный production API:
`go(view)`, `setRenderer(mode)`, `tick()`, `state`, `jobs`, `windowHistory()`, `exportFrame()`,
`setTheme(id, { persist: true })`, `showThemes()`, `toggleGrid()`.
Транспорт и реальные источники намеренно не добавлены. Пример отдельного графика — в `examples/`.


## Общая модель координат

`TuiCoordinates.model({ width, height, bounds, windowMs })` — чистая функция: метки X/Y,
середина и положение нуля. `TuiCoordinates.render(svg, { ...options, grid: true })` рисует
рамку и возвращает ту же модель. Видимую ось нельзя подписывать независимо от bounds графика.

## Палитра

`TuiThemes.all` — восемь пресетов. `TuiThemes.get(id)` безопасно возвращает SACRA для
неизвестного ID. `TuiThemes.apply(id, roots)` устанавливает все 17 переменных на переданных
DOM-корнях. Сам модуль не записывает хранилище и не перезапускает симуляцию.

`SacraTUI.setTheme(id, { persist: false })` — живой предпросмотр, не фиксация выбора.
Отмена восстанавливает прежнюю палитру; подтверждение сохраняет ID, если это разрешено браузером.
Экспорт JSON содержит семантические роли, не терминальный escape-код и не btop `.theme`.
