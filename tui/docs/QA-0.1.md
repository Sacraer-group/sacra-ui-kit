# Проверки прототипа SACRA / TUI 0.1

Проверено 2026-10-02 в рабочем Linux-контейнере. Это отчёт об этом архиве,
а не подтверждение совместимости с нативными терминалами.

## Выполнено

- `node --check assets/app.js` и `node --check assets/charts.js`: синтаксические ошибки не найдены.
- `node tests/charts.test.cjs`: **15/15** проверок. Нулевая линия, null/NaN/Infinity,
  временной разрыв, границы окна, два ряда, ограничение памяти, ASCII/sparkline и бары.
- `python3 tests/browser.py`: **75/75** проверок, **Chromium 144.0.7559.96**.
  Фактический список — `tests/browser-results.json`.
- Проверены все пять экранов на ширинах 320, 390, 768, 1440 и 1920 px.
  Тест проверяет отсутствие горизонтального переполнения всей страницы; широкий код и
  фиксированное TUI-окно могут прокручиваться локально.
- Проверены режимы Pixels / Octant / ASCII, пауза, шаг по sample, сценарии
  normal / gaps / zero / missing, клавиатурный курсор и экспорт JSON/TXT.
- Проверены независимые checked/selected/focus, кастомный listbox, валидация поля,
  табы, страницы, поиск/выбор задач и подтверждение изменения только локальных данных.
- Копирование проверено через реальную вставку в отдельное поле. Отказ проверен
  отключением механизма копирования: без ложной зелёной галочки, с ручным fallback.
- Режим reduced-motion начинает симуляцию на паузе. Сетевых запросов приложения
  и ошибок JavaScript в тестируемых сценариях не обнаружено.
- Скриншоты заново сделаны после изменения стартового экрана на каталог компонентов
  и применения единого терминального кегля.

## Важное ограничение среды

Политика авторского браузерного контейнера блокирует навигацию на `file://` и локальный
HTTP. Поэтому браузерные тесты используют **загрузку исходников через Playwright
`set_content`, `add_style_tag`, `add_script_tag`**, без изменения байтов CSS/JS.
До загрузки проверяется наличие всех подключаемых локальных ресурсов.
Это проверка интерфейса и его исходников, **не end-to-end тест открытия ZIP/URL**.
В поставляемом `index.html` зависимости остаются отдельными относительными файлами.

## Не проверено и не реализовано

Safari, iOS, VoiceOver и нативные терминалы отдельно не тестировались.
Нет PTY/ANSI-эмулятора, Kitty negotiation/transport, нативного Octant-шрифтового вывода,
реальной телеметрии, shell-команд, файловых операций или интеграции с сервером.
Проверки произвольных широких Unicode-графем относятся к будущему нативному backend.

Наличие 75 успешных сценариев не означает полного аудита доступности либо покрытия
всех браузеров и всех сочетаний ввода.
