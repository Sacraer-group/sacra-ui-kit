# Примеры

`minimal-chart.html` — отдельный браузерный пример на `TuiCharts` + `TuiCoordinates`, без оболочки лаборатории и `app.js`.
Та же техническая рамка и шкалы, прозрачный растер данных, адаптивные подписи;
числовой альтернативный вывод — раскрываемая таблица.
`frame.txt` — текстовая компоновка, не вывод реального терминала.
`session.json` — маленькая synthetic-сессия с нулём и пропуском.
`layout.schema.json` — предлагаемый контракт входных данных для будущего native renderer.
Всё это проектные материалы, не привязки к терминальным библиотекам.
