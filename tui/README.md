# SACRA / TUI Lab 0.2

Браузерная симуляция терминального интерфейса и проект отдельного TUI-слоя SACRA.
**Это прототип, не нативный терминальный клиент.** Все числа, процессы и задачи синтетические.

## Открыть

Распакуй весь архив и открой **`index.html`** в браузере. Папка `assets/` должна оставаться рядом.
Сборка, npm, сеть, сервер и установленный Nerd Font для просмотра не нужны.

При ограничениях браузера на локальные файлы можно запустить из каталога архива:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765`. Остановить сервер — Ctrl+C. Это только раздача статических файлов.

## Что смотреть

| Экран | Содержимое |
|---|---|
| **1 · Компоненты** | Стартовый экран. 12 групп: действия, checkbox/radio, select, input, tree, статусы, прогресс, вкладки, пагинация, empty/error, logs, dialogs |
| **2 · Задачи** | Поиск, фильтры, сортировка, список + инспектор, JSON, подтверждение изменения |
| **3 · Графики** | Pixels / Octant / ASCII на одинаковых данных, ноль/разрывы/N/A, курсор, экспорт |
| **4 · Монитор** | Пример применения: CPU/RAM/сеть, sparkline, метрики, процессы, события, бюджеты ресурсов |
| **5 · Правила** | Геометрия клеток, роли цветов, клавиатура, отрисовка, состояния, план интеграции |

Кнопка **«Только TUI»** / `v` скрывает браузерную обложку.
Размеры **80 / 120 / 160** — ширина в знакоместах. **AUTO** использует доступную ширину.
Фиксированное широкое окно прокручивается внутри макета, не растягивает страницу.
Высота не фиксирована: это каталог для исследования дизайна, не эмулятор PTY.

## Новое в 0.2: координаты + темы

Все полноразмерные графики получили техническую рамку по визуальному референсу:
пунктирный периметр, кресты в углах, малые/большие деления, сетку и центральное перекрестие.
Шкалы настоящие: CPU/GPU 0–100%, RAM 0–16 GiB, сеть 0–32 MiB/s в этом демо.
Центр рамки не объявляется нулём: у положительного диапазона ноль остаётся внизу.
Pixels / Octant / ASCII используют одну и ту же систему координат.
Курсор показывает X и Y, а у сети — обе серии. На недоступном sample нет ложной точки.

**`g` / «Сетка»** включает/скрывает внутренние направляющие и деления. Рамка, числовые оси,
легенда и единицы остаются. На узком графике меток меньше, но диапазон тот же.
Восьмиуровневые мини-sparkline и процентные полосы намеренно сохраняют компактный формат.

**`t` / кнопка палитры** открывает собственный селектор с восемью вариантами:
SACRA Graphite, Nord, Gruvbox Dark, Dracula, Tokyo Night, Solarized Dark,
Solarized Light и Mono Graphite. Выбор даёт живой предпросмотр. Enter / «Применить»
подтверждает его, Esc / «Отмена» возвращает предыдущие цвета. Кнопка SACRA возвращает
базовый вариант; «↓ JSON» выгружает роли текущей палитры, не файл btop.

Меняются TUI, его графики, диалоги и уведомления. Внешняя обложка остаётся в SACRA.
Переключение не сбрасывает текущий экран, ввод, задачи и паузу. Графики перекрашиваются
сразу, даже на паузе. Выбор сохраняется локально, когда браузер разрешает localStorage;
при запрете тема действует до перезапуска, интерфейс не выдаёт это за сохранение.

Семейства палитр адаптированы к ролям SACRA, а не импортированы из ultra-mog.
Это не парсер `.theme` btop и не нативная ANSI/256-color реализация.
Правила и источники: [docs/THEMES.md](docs/THEMES.md).

## Клавиши

Кликни внутри терминального макета. `1–5` меняют экран, `p` — пауза, `w` — 1/5/15 минут,
`→` на паузе — один sample. На самом графике `←/→`, Home/End двигают курсор.
В задачах `j/k`, `↑/↓` выбирают строку, `s` меняет сортировку, `/` включает поиск.
`t` — палитры, `g` — сетка; `:` открывает команды интерфейса, `?` — справку. Esc отменяет/закрывает.
Tab и Shift+Tab работают как обычная браузерная навигация, без ловушки фокуса.

## Источник графиков

Из `Sacraer-group/ultra-mog` на **7975fee** адаптированы разбиение истории на непрерывные сегменты,
целочисленный растер линий, структура низкоразрешённого графического слоя,
Octant/ASCII-ветки и восьмиуровневые sparkline/бары. **Ни одна тема ultra-mog не импортирована. Его оформление, компоновка, рамки, навигация и подписи не используются как дизайн-референс.**

Это самостоятельная TUI-ветка SACRA: по умолчанию открывается каталог компонентов, а монитор — только один из примеров применения. Внутри симулятора один кегль; иерархия строится на группировке, контрасте и пустом пространстве, не на размере текста.

Тема по умолчанию сохраняет все 17 цветовых токенов SACRA UI 1.4.3. Альтернативы заменяют
те же роли. Первый ряд графика использует акцент темы, второй — цвет основного текста и
символ `+` в легенде. Семантические состояния сохраняют текстовые метки.

Octant здесь рисуется прямоугольными субклетками в Canvas, а не редкими Unicode-глифами.
Pixels — браузерный растер, а не отправка Kitty escape-последовательностей.
Описание переноса и границ: [docs/SOURCES.md](docs/SOURCES.md).

```text
index.html

  coordinates-themes.css     оформление координат и собственного селектора тем

  app.js                     симуляция, экраны, клавиатура, локальные данные
  mark.svg                   знак SACRA
examples/
  frame.txt                  текстовый пример компоновки
  session.json               пример данных и интерфейсного состояния
  layout.schema.json         компактный контракт данных макета
  minimal-chart.html         отдельный пример отрисовки
  minimal-chart.js
  minimal-chart.css
  README.md

docs/
  DESIGN.md                  проработанная модель TUI-слоя
  COMPONENTS.md              каталог, состояния и взаимодействия
  THEMES.md                  палитры, scoping, хранение и экспорт
  SOURCES.md                 что из ultra-mog, что спроектировано здесь

  ULTRA-MOG-LICENSE.txt       MIT notice исходного проекта

  charts.test.cjs             проверка вычислений без зависимостей
  browser.py                  браузерные проверки через Playwright
  browser-results.json        фактический результат
  coordinates-themes.test.cjs координаты, палитры и прозрачный растер
  themes_browser.py           поведение тем, координат и независимого графика
```

## Проверки

```sh
node tests/charts.test.cjs
node tests/coordinates-themes.test.cjs
# Для browser.py нужны установленный Playwright и Chromium.
SACRA_CHROMIUM=/path/to/chromium python3 tests/browser.py
SACRA_CHROMIUM=/path/to/chromium python3 tests/themes_browser.py
```

Для обычного просмотра тестовые зависимости не нужны. Правила запуска браузерных тестов и
ограничения окружения описаны в `docs/QA.md`.

Этот каталог хранится как `tui/` в private `sacra-ui-kit`. Пакет не читает системную телеметрию,
не исполняет shell-команды, не отправляет данные и не выполняет системные операции. Глобальная установка Codex берёт этот reference вместе со skills из корня репозитория.
