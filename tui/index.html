01 / КЛЕТКА

Не уменьшенный веб.

Отступы в символах и строках, прямые рамки, текстовые состояния. Без теней, скруглённых карточек и иконок, требующих шрифта.

02 / ДАННЫЕ

Пробел тоже информация.

Ноль не исчезает. Пропуски не соединяются. Общая шкала для сравниваемых серий; минимум, максимум и единица рядом.

03 / КОНТРОЛЬ

Фокус виден всегда.

Акцент темы — навигация. Успех — отдельное состояние с [OK]. Перед изменением задачи — диалог; Esc отменяет, а не выполняет действие.
