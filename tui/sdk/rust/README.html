SACRA TUI / Native Rust

Crate sacra-tui, импорт sacra_tui. Настоящая Rust-отрисовка внутри процесса: без Go-worker, браузера и FFI.

Запуск

Из tui/sdk/rust:

cargo run --locked --example blocks
cargo run --locked --features ratatui --example ratatui
cargo run --locked --release --features terminal --bin sacra-tui-rs -- --demo --color truecolor

q / Esc / Ctrl-C — выход; p — пауза; стрелки — прокрутка/шаг; Tab — фокус; Enter — выбор; t — тема. Демо synthetic; библиотека не симулирует реальные события.

Встраивание

[dependencies]
sacra-tui = { path = "../sacra-ui-kit/tui/sdk/rust" }

12 отдельных блоков, восемь семантических тем, типизированные JSON placeholders. Данные/ввод/таймеры принадлежат host-приложению. Feature ratatui предоставляет FrameWidget для существующего Ratatui Terminal; terminal включает интерактивное CLI. Оба опциональны.

Полное руководство: README.md. Проверки: QA.md. Эти Markdown-файлы — исходники UTF-8 для редактора или GitHub.

Проверено

Linux x86_64: 10 integration tests + doctest, Clippy без warnings, 7 CLI/PTY-проверок выхода, resize и восстановления терминала. Нативные macOS/Windows здесь не запускались.

Границы

Это не полный порт форм/диалогов TUI Lab, не универсальный DAG layout и не Pixels/Octant/Kitty backend. При узкой ширине топология становится списком, шрифт не уменьшается. Crate использует serde, serde_json, unicode-segmentation и unicode-width; Cargo.lock фиксирует проверенные зависимости. На первом build Cargo может обращаться к crates.io. Публикация в публичный registry не выполнялась.
