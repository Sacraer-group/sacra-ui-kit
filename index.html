01 / MOTION LAB · REAL WASM

Математика.
В движении.

Шесть поверхностей с общим API. Генерация и проекция вершин — C → WebAssembly. Отрисовка — Canvas 2D, интерфейс — JavaScript.

Движение под контролем. Вне видимой области и в скрытой вкладке расчёты приостанавливаются. При prefers-reduced-motion автозапуск отключён; запустить можно кнопкой. FPS измеряется в браузере, а не обещается. Формы декоративные, это не телеметрия.

03 / APPLICATION PATTERNS
Из компонентов —
рабочий интерфейс.
Дерево, фильтры, таблица, доска, логи, команды и инспектор. Одно локальное состояние: изменение задачи видно во всех представлениях.
01 / Найти и выбрать
Сворачиваемое дерево, поиск, фильтр по узлу, съёмный chip, сортировка, страницы и массовый выбор.
02 / Управлять
Канбан с drag-and-drop и выбором статуса с клавиатуры. Инспектор редактирует те же данные; история действий сохраняется в сессии.
03 / Наблюдать
Фильтруемые логи, управляемый демопоток, экспорт, командная строка и копируемый command block. Никакого доступа к shell.
Подключить рабочий пример
const workspace = SacraWorkspace.mount(
  document.querySelector('#workspace'),
  { persist: false }
);
// workspace.snapshot() → копия массива задач
// workspace.destroy() → очистка и остановка таймеров
// persist: true → localStorage только для демозадач




04 / VISUAL LANGUAGE
Дисциплина × эксперимент.
Swiss-сетка и cyber-геометрия.
Без радуги, чёрной пустоты и декора поверх данных.




01 / SWISS + BRUTALIST
Сначала структура.
Номер раздела, крупный заголовок, жёсткие оси и тонкие линейки. Углы 2–8 px; без мягких карточек-пузырей.


02 / Y2K + ACID
Потом характер.
Деформированные кольца, муар и векторные оболочки. Вместо голографической радуги — линии цвета жёлтого акцента.


03 / TECHNICAL UI
Всегда смысл.
Шкалы, индексы, рамки и числовые индикаторы. Реальные данные отдельно; декоративные формы и демо — с подписью.
