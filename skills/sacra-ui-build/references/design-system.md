# SACRA UI compact reference

Palette: canvas `#15191F`, surface `#1B2027`, raised `#222831`, sunken `#11151A`, hover `#29313B`, border `#2A3038`, strong border `#414B58`, text `#F2F4F6`, muted `#9BA3AE`, subtle `#747E8C`, accent `#F2CC4D`, success `#45BF92`, danger `#EF7B6D`.

Use SF Mono / Liga SFMono Nerd Font / Menlo / monospace and SVG icons. Base spacing is 4 px. Radii are 2/4/6/8 px. Working content uses calm graphite surfaces. Editorial regions may use technical frames, dots, scanlines, wireframes and numeric labels in the same palette.

Reusable classes include `s-btn`, `s-panel`, `s-field`, `s-input`, `s-check`, `s-switch`, `s-badge`, `s-tabs`, `s-table`, `s-alert`, `s-progress`, `s-toast`, `s-empty`, `s-skeleton`, `s-spinner`, `s-card`, `s-metric`, `s-chip`, `s-list`, `s-avatar`, `s-pagination`, `s-menu`, `s-tooltip`, `s-dialog`, `s-kicker`, `s-editorial-title`, `s-register`, `s-rail`, `s-tech-frame`, `s-readout`, `s-scale`.

Never use documentation-only `ds-*` classes in product UI. Keep keyboard focus visible. Success uses green feedback; focus uses yellow. Do not fake telemetry or confidence values.
