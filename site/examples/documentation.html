Начало работы

Документация строится вокруг коротких объяснений, чётких технических блоков и повторяемой навигации. Этот пример использует синтетический endpoint.

02

Создание задачи

Выбранный язык синхронизируется между всеми code-group на странице. Нажатие Copy использует общий SacraUtils.copy: зелёная галочка + toast появляются только после успешного копирования.

POST /v1/jobs · cURL
curl -X POST "$API_BASE/v1/jobs" \
  -H "Authorization: Bearer $API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input":"demo"}'
POST /v1/jobs · Python
import requests

response = requests.post(
    f"{API_BASE}/v1/jobs",
    headers={"Authorization": f"Bearer {API_TOKEN}"},
    json={"input": "demo"},
    timeout=30,
)
response.raise_for_status()
POST /v1/jobs · Go
body := strings.NewReader(`{"input":"demo"}`)
req, _ := http.NewRequest("POST", apiBase+"/v1/jobs", body)
req.Header.Set("Authorization", "Bearer "+apiToken)
req.Header.Set("Content-Type", "application/json")
resp, err := http.DefaultClient.Do(req)
POST /v1/jobs · TypeScript
const response = await fetch(`${API_BASE}/v1/jobs`, {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${API_TOKEN}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ input: 'demo' }),
});
03

Ответ и состояние

Для request/response можно использовать парную раскладку. На узких нама складывается в одну колонку.

REQUEST
{
  "input": "demo"
}
RESPONSE · 202
{
  "id": "job_demo_01",
  "state": "queued"
}
Хороший паттерн

Код рядом с объяснениен; язык меняется глобально; кнопка копирования ссегда остаётся в одинаковом месте.

04

Ошибки и ограничения

Ошибки показываются текстом и структурой, не только цветом.

429 · Too many requests

Пример ошибки. Не используйте красный как единственный канал: сохраняйте код, заголовок и понятное действие.
