Установка

Guide-паттерн начинается с короткого результата, затем показывает шаги и только необходимый код.

1

Добавьте пакет

Используйте одну команду и оставьте рядом контекст, зачем она нужна.

2

Подключите конфигурацию

Показывайте следующий обязательный шаг сразу под первым.

TERMINAL
example install sacra-demo
example init --profile technical
02

Настройка

Один и тот же conceptual snippet можно показать на нескольких языках, сохранив единый визуальный ритм.

config.ts
export const config = {
  mode: 'technical',
  accent: 'yellow',
};
config.py
config = {
    "mode": "technical",
    "accent": "yellow",
}
config.go
config := Config{
    Mode: "technical",
    Accent: "yellow",
}
Синхронный язык

Если на странице несколько language-group, выбор языка применяется ко всем совместимым блокам и сохраняется в localStorage.

03

Проверка

Заканчивайте guide проверяемым результатом, а не абстрактным “готово”.

VERIFY
example doctor
# expected: profile=technical status=ok
Готово

У читателя есть явная команда проверки и ожидаемый результат.
